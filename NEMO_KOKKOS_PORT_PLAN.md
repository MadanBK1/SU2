## Key findings

### Blockers (ranked)
1. **Gas model is stateful.** `CNEMOGas`/`CSU2TCLib` keep thermodynamic state in members between calls (`rhos`, `T`, `Tve`, `Cvtrs`, `eves`, `ws`, `taus`, even loop counters `iSpecies/jSpecies`). There are hidden ordering dependencies:
   - `ComputeTemperatures` reads `Cvtrs` from a previous `GetSpeciesCvTraRot`.
   - `ComputeEveSourceTerm` reads `ws` from the previous `ComputeNetProductionRates`.
   - `ThermalConductivitiesWBE` reads `mus/phis` from `ViscosityWBE`.
   - `GetChemistryEquilConstants` does `std::string` compares per reaction per point.
   **Fix:** rewrite as stateless `KOKKOS_INLINE_FUNCTION`s over read-only tables (`NEMOGasTables`). Mutation++ stays host-only.
2. **Numerics are virtual objects with per-object scratch.** Each `CNEMONumerics` owns its own `new CSU2TCLib`, uses `new[]` buffers, and returns `su2double**` Jacobians. **Fix:** POD flux functors using stack arrays sized `MAXNVAR`.
3. **Edge loops are serial.** No coloring and no reducer: NEMO doesn't override `GetHasHybridParallel`, and `GetEdgeColoring()` degenerates to one colour because Kokkos builds forbid OpenMP. **Fix:** atomics, or `colorSparsePattern(GetSparsePattern(FV,0))` called directly.
4. **Jacobian is re-uploaded on every solve.** The first `DeviceMatVec` uses `matrix_on_device=false`, so `HtDTransfer` copies the full nnz·nVar². ILU and Jacobi are factored on the host, then mirrored. `dia_ptr` and `edge_ptr` aren't mirrored, and `d_row_ptr` covers only `nPointDomain+1` rows.
5. **`CVertex` is pointer-AoS**, so it needs per-marker flattening. `CEdge::Nodes` has no whole-array accessor. Everything else (`Coord`, `Volume`, edge `Normal`, CSR, `Solution`/`Primitive`, gradients) is contiguous `C2DContainer` and can be copied once.
6. **Kokkos init is implicit** (a static in `allocation_toolbox.hpp`). Finalize runs after `MPI_Finalize`. Device-resident work needs explicit init and finalize.

### Pre-existing issues in the CPU reference (verify before using as ground truth)
- `CSU2TCLib.cpp:1576-1588` `ComputeKeqConstants`: `unsigned short iIndex = int(pwr)-14` wraps when N < 1e14 cm⁻³, which selects the highest-density row. Affects low-density/high-altitude cases.
- `CNEMOEulerSolver::ComputeConsistentExtrapolation` doesn't recompute dPdU/dTdU/dTvedU/Cvve at reconstructed states (TODO in code). The implicit Jacobian uses stale or zero arrays.
- NS + Green-Gauss: the gradient is of Y_s, but MUSCL adds it to ρ_s.
- `CNEMOGas::ComputedPdU` with ionization: dPdU for the last ion (NO+) is only decremented (`-=`), never assigned, so it accumulates across calls. `ComputedTdU` never writes the electron entry. `GetSpeciesCvTraRot` fills only species nEl..nHeavy-1 (NO+ Cv_tr = 0 in AIR-7).
- `msw.cpp:64-65` allocates `Flux` twice (leak). AUSMPWplus is declared but not implemented.

### Data layout
- nVar = Ns+nDim+2 (U = ρ_s, ρu_i, ρE, ρE_ve). nPrimVar = Ns+nDim+8 (Euler) / +10 (NS).
- Primitive V layout: ρ_s | T | Tve | u_i | P | ρ | h | a | ρCv_tr | ρCv_ve | [μ, μ_t].
- Secondary per point: dPdU, dTdU, dTvedU (nVar), eves, Cvves (Ns), Gamma.
- Passive Kokkos build means su2double == double.

## Call chain (steady implicit, MGLEVEL=0)
1. `CFluidIteration::Iterate` → `CMultiGridIntegration::PreSmoothing`.
2. `Preprocessing`:
   - `SetPrimitive_Variables` (Cons2Prim per point);
   - non-physical Allreduce;
   - zero `LinSysRes`/Jacobian;
   - GG/LS gradients + comms;
   - limiter + comms.
3. `SetTime_Step` (edge + vertex + point).
4. `Space_Integration`: Upwind/Centered → Viscous → Source → BCs.
5. `ImplicitEuler_Iteration`:
   - Prepare: diag += Vol/dt, RHS, `SetResidual_RMS` Allreduce;
   - `System.Solve`;
   - Complete: under-relaxation, `AddSolution`, SOLUTION comms.
6. `AdaptCFLNumber`.

## Validation policy (from Step 5 on)
- **Portability rule.** Device kernels use plain source-order arithmetic, statement by statement as the CPU code. No compiler-specific evaluation order is pinned (the GCC-13 `-ffast-math` FMA/value-barrier form of the 2D least-squares kernel from Step 3 was removed: nvcc/icpx/hipcc contract differently).
- **Exactness gate = strict IEEE build** (`build-kokkos-strict`: `-Denable-fast-math=false`, `-ffp-contract=off`):
  - `SU2_KOKKOS_STAGE_VERIFY=1` per-stage A/B (gradient, limiter, time step, upwind residual + Jacobian + Non_Physical): 0 non-bitwise entries on all configuration variants (`/home/claude/runs/ab_variants.sh`).
  - `REF_MODE=HOST RES_TOL=0 FIELD_TOL=0 check.sh`: ENABLE_KOKKOS=YES vs YES with every NEMO stage forced to the host (`SU2_KOKKOS_NEMO_HOST=all`, same Kokkos linear solver) → bitwise restart files.
  - `REF_MODE=NO FIELD_TOL=1e-12` cannot pass on invwedge, also before Step 5: YES uses the Kokkos device-resident linear solver, whose reductions are ordered differently from the host solver (6.7e-10 fields after 11 iterations; residual rows identical). That is a linear-solver property, isolated by REF_MODE=HOST.
- **Production gate (`-ffast-math` build).** Device code and CPU templates are contracted/re-associated differently, so they agree to a few ULP. NEMO's MUSCL non-physical-reconstruction switch (CheckNonPhys + sticky Non_Physical, ~2.4e4 flagged states per iteration on invwedge) amplifies ULP noise into O(1e-4) field differences after 11 iterations, the same way recompiling the CPU code does. Gates:
  1. `PHYS_SCALE=1 RES_NOISE_ORDERS=10 check.sh super_cat thermalbath` (FIELD_TOL 1e-9, RES_TOL 2e-6): species scaled by mixture density, momenta by max sqrt(rho*rhoE), round-off residual columns (>10 orders below the row max, e.g. rms[RhoU] of the 0-D bath) ignored.
  2. `check_converged.sh` (NO vs YES, long run, field ≤ 1e-6 after physical scaling, history within HIST_TOL) for a case that converges. invwedge_ausm at its cfg CFL (3, 5 BCGSTAB iterations) does **not** converge: CPU-only it limit-cycles at rms[Rho_0] ≈ -2.7 from ~500 to 1300+ iterations (first order also stalls, CFL 20/50 stall or diverge), so a converged comparison is impossible there. NO and YES show the same stall level.
  3. invwedge noise-floor comparison (`check_noisefloor.sh`): |YES_prod − NO_prod| must not exceed K=10× |NO_strict − NO_prod|, i.e. the device must not perturb the solution more than recompiling the CPU code with/without fast-math.
- **ENABLE_KOKKOS=NO** stays bit-identical to the previous commit (`check_no_identity.sh`: restart files and screen history, 4 cases).

## Batch A status (2026-11-20): AUSM+M sensor, CFL adaptation, axisymmetry, AUSM+M supersonic BCs, RK, dual time
All five items make device-resident mode ON where it was OFF before; every new path is bitwise vs the CPU in the strict build.
- **Hooks (SU2_CFD core, no-op defaults)**: `CSolver::AdaptCFLNumber_Device` (called by `AdaptCFLNumber` instead of its point loop when there is no turbulence / species solver) and `CSolver::SetDualTime_Device` (called by `CIntegration::SetDualTime_Solver` instead of its host loops). `CNEMOEulerSolver::SetResidual_DualTime` overrides the base class (device stage, or the host-stage hook + base).
- **1. AUSM+M pressure diffusion sensor** (`Device_PressureSensor`, `CNEMOKokkosData::ComputePressureSensor`): point kernel over the point CSR (CPoint::GetPoints order, std::min semantics), new residency group `G_SENSOR`, device halo exchange `HaloQuantity::SENSOR` (MPI `SENSOR` comm, Step-10 machinery; `SU2_KOKKOS_NEMO_HALO=host` legacy path works too). Resident mode only; host-authoritative mode keeps the host loop; `SU2_KOKKOS_STAGE_VERIFY=1` compares it (stage `PressureSensor`).
- **2. CFL adaptation** (`AdaptCFLNumber_Device`, `CNEMOKokkosData::AdaptCFL`): the per-point LocalCFL update (UnderRelaxation, reduceCFL / canIncrease / resetCFL flags, min / max clamps, MG factor) with a custom {min, max, sum} reducer initialised to the CPU values (ordered on Serial = bitwise; the sum is order-dependent on GPUs, monitoring only). The global logic (linear-solver residual, nonlinear residual history, flags, MPI reductions) stays in the host code. Test params `CFL_ADAPT_PARAM= (0.5, 1.5, 1.0, 20.0, 0.9, 2)`: growth, MAX clamp, full resets and per-point reductions all occur in 21 iterations (invwedge_ausm: AVG_CFL 2.99 -> 19.3 -> reset 1.0 -> ...).
- **3. Axisymmetric source + auxiliary gradients**: `CSource_NEMO::ComputeAxisymmetric` (2D) fused into the source kernel after chemistry / V-T in CPU order (residual + Jacobian, NaN counter `Axisymmetry`, also with MONOATOMIC), viscous part with the device `ComputeAxisymmetricAuxGradients` (AuxVar for y > EPS on all points, GG / WLS gradient with the existing kernels at nvg = 3, idxVel = -1; symmetry rows corrected with the CPU `correctGradientsSymmetry` like the primitive gradient; halo exchange `AUXVAR_GRADIENT`; group `G_AUXVAR`; stage `AxisymAuxGradient`). axi_visccone: resident ON, bitwise vs REF_MODE=HOST; added to the check.sh default case list.
- **4. BC_Supersonic_Inlet / Outlet with AUSM+M**: the shared boundary numerics keep Gamma / Sensor from the last BC that set them. Replayed on the host (`RecordBoundaryNumerics` in BC_Far_Field / BC_Outlet / BC_Supersonic_Outlet: last domain vertex point; FAR / OUTLET: Gamma_i = Gamma(p), Gamma_j = Gamma_infty, Sensor = Sensor(p); SUPERSONIC_OUTLET: Gamma_i = Gamma_j = Gamma(p)), reset every space integration; the device kernel gets the three scalars (2 x 8 B DtoH in resident mode). Supported when a setter precedes the marker in the BC order on every rank (constructor check + Allreduce); otherwise the CPU reads uninitialised members in the first iteration -> host BC (reason printed).
- **5. RK and dual time**: device `Explicit_Iteration_impl<RUNGE_KUTTA_EXPLICIT / CLASSICAL_RK4_EXPLICIT>` (`ExplicitRKUpdate`; RK4 Solution_New lives on the device, Set_OldSolution also copies it since CMultiGridIntegration calls Set_NewSolution right after); dual time: device SetResidual_DualTime (1st / 2nd order, Jacobian diagonal; stage `DualTimeSource`), SetDualTime_Solver state shift (`DualTimeShift`), SetTime_Step dual-time branches (UNST_CFL start-up min, explicit dt clamp), group `G_TIMEN` (Solution_time_n / n1). Dual time no longer forces eager residual sync. What forced OFF before: `Device_ResidentUnsupported` ("dual time stepping", "Runge-Kutta time integration") and `Device_DeferralUnsupported` (host SetResidual_DualTime without hook).
- New A/B variants (ab_variants.sh and ab_resident.sh): am_impl am_first cfl_ausm cfl_am cfl_sc axi axi_gg axi_inv axi_expl supout_am supin_am supinout_am tb_rk tb_rk4 rk_ausm rk4_am dt2 dt1 dt_expl dt_unstcfl dt_sc; all report resident ON.
