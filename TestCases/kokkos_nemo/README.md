# Kokkos NEMO validation scripts

These are developer scripts for the `su2kokkos` branch. Paths are currently hard-coded for the Claude cloud workspace (`/home/claude/su2`, `/home/claude/runs`, `/home/claude/meshes`). Change them to match your machine.

Meshes come from su2code/TestCases: `invwedge.su2`, `viscwedge.su2`, `5x5Mesh.su2`.

| Script | Purpose | Gate |
|---|---|---|
| `check.sh` | Runs ENABLE_KOKKOS=NO and YES (or `REF_MODE=HOST`: all NEMO stages forced to host) for invwedge_ausm, thermalbath and super_cat (default), partial_cat and axi_visccone (Step 8, on request), then compares residual rows and restart fields. | Strict build: `REF_MODE=HOST RES_TOL=0 FIELD_TOL=0` must be bitwise. |
| `check_noisefloor.sh` | Production (fast-math) build. The YES-vs-NO deviation must stay within 10× the CPU fast-math vs strict deviation. `CASE=invwedge_ausm` (default) or `CASE=super_cat` (Step 8; history compared relative to max(\|value\|, 1) because of the force / heat-flux columns). | |
| `check_no_identity.sh` | Checks that the ENABLE_KOKKOS=NO output is bit-identical to a pre-change binary. | |
| `ab_variants.sh` | Per-stage A/B over config variants, using `SU2_KOKKOS_STAGE_VERIFY=1` (gradient, limiter, time step, upwind, source, BCs). Step 7 variants: `tb*` (thermal bath: explicit/implicit, frozen, VT limiting, AIR-5), `supersonic` (supersonic inlet/outlet markers), `subout`/`subout_am` (subsonic outlet branch). Step 8 variants `sc_*` (super_cat: supercatalytic, partially catalytic explicit, Gupta-Yos, Sutherland, Green-Gauss, heat-flux wall, explicit, N2, Jacobi) + `partial_cat`, `axi_visccone`: device transport, viscous residual (Viscous stage), NS walls, viscous far field. | Strict build: `AB OVERALL: PASS` (0 non-bitwise entries). |
| `ab_resident.sh` | Step 6: device-resident mode (with `SU2_KOKKOS_PRECOND_VERIFY=1`, `SU2_KOKKOS_NEMO_POISON=1`) vs `SU2_KOKKOS_NEMO_RESIDENT=0`, 21 variants, plus the per-iteration transfer ledger of both (the ON ledger includes the PRECOND_VERIFY matrix download / precond upload). Step 8: 13 NS variants (`sc_*`, LIFT/DRAG/TOTAL_HEATFLUX in the screen history: Friction_Forces host sync; `sc_output`: volume output every 3 iterations, .vtk compared too). | Strict build: `AB RESIDENT OVERALL: PASS` (bitwise restart + history, precond A/B 0 non-bitwise). |
| `check_nonnemo_kokkos.sh` | ENABLE_KOKKOS=YES on the QuickStart NACA0012 Euler case (FGMRES+ILU, BCGSTAB+JACOBI), OLD vs NEW binary. | Bit-identical (the shared linear-algebra changes do not alter non-NEMO solvers). |
| `NEMOGasKokkos_validation` (UnitTests, `ninja -C <build> UnitTests/nemo_gas_kokkos_validation`, run `... 5000 1e-10`) | Pointwise device thermo / chemistry / Step 8 transport (WILKE, GUPTA-YOS, SUTHERLAND) vs CSU2TCLib. | Strict build 100 % bitwise; PASS in both builds. |
| `check_converged.sh` | Converged-solution comparison. Note: invwedge_ausm stalls near rms[Rho_0] ≈ -2.7 and does not converge. | |

Debug environment variables (ENABLE_KOKKOS= YES): `SU2_KOKKOS_NEMO_HOST=c2p,grad,lim,dt,upwind,source,bc,transport,viscous|all` forces stages to the host (`transport`: NS transport properties on the host with the per-point gas-state replay; `viscous`: host viscous residual); `SU2_KOKKOS_NEMO_EAGER=1` downloads the device residual accumulator after every device stage; `SU2_KOKKOS_NEMO_MIXED=1` lets device stages upload a non-zero host accumulator (after a host stage); `SU2_KOKKOS_STAGE_VERIFY=1` per-stage A/B. Step 6: `SU2_KOKKOS_NEMO_RESIDENT=0` disables the device-resident mode; `SU2_KOKKOS_NEMO_POISON=1` NaN-fills stale host copies (debug); `SU2_KOKKOS_PRECOND_VERIFY=1` compares the device Jacobi/ILU(0) build with the host build.
