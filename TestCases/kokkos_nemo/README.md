# Kokkos NEMO validation scripts

These are developer scripts for the `su2kokkos` branch. Paths default to the old cloud workspace (`/home/claude/su2`, `/home/claude/runs`, `/home/claude/meshes`) but can be overridden with the `SU2_ROOT`, `RUN_DIR` and `MESH_DIR` environment variables.

Meshes come from su2code/TestCases: `invwedge.su2`, `viscwedge.su2`, `5x5Mesh.su2`.

| Script | Purpose | Gate |
|---|---|---|
| `check.sh` | Runs ENABLE_KOKKOS=NO and YES (or `REF_MODE=HOST`: all NEMO stages forced to host) for invwedge_ausm, thermalbath and super_cat (default), partial_cat and axi_visccone (Step 8, on request), then compares residual rows and restart fields. Batch A: axi_visccone is in the default case list; `invwedge_am` (AUSM+M) on request. Step 10: `NP=<n>` (mpirun prefix, `MPI_OPTS` default `--mca osc ^rdma`), `REF_MODE=YES` + `REF_BIN` / `REF_NP` (compare binaries / rank counts), `RUN_TAG`, `EXTRA_CFG="KEY= VAL;..."`. | Strict build: `REF_MODE=HOST RES_TOL=0 FIELD_TOL=0` must be bitwise. Step 10 (strict MPI build `build-kokkos-strict-mpi`): `NP=2 REF_MODE=HOST RES_TOL=0 FIELD_TOL=0` bitwise (also with `SU2_KOKKOS_NEMO_POISON=1`, `EXTRA_CFG='KOKKOS_GPU_AWARE_MPI= YES'`, `SU2_KOKKOS_NEMO_HALO=host`, `SU2_KOKKOS_NEMO_RESIDENT=0`); `NP=1 REF_NP=0 REF_MODE=YES REF_BIN=<non-MPI strict>` bitwise. |
| `check_noisefloor.sh` | Production (fast-math) build. The YES-vs-NO deviation must stay within 10× the CPU fast-math vs strict deviation. `CASE=invwedge_ausm` (default) or `CASE=super_cat` (Step 8; history compared relative to max(\|value\|, 1) because of the force / heat-flux columns). | |
| `check_no_identity.sh` | Checks that the ENABLE_KOKKOS=NO output is bit-identical to a pre-change binary. | |
| `ab_variants.sh` (Step 10: `NP=2`, MPI build, rank-0 counts) | Per-stage A/B over config variants, using `SU2_KOKKOS_STAGE_VERIFY=1` (gradient, limiter, time step, upwind, source, BCs). Step 7 variants: `tb*` (thermal bath: explicit/implicit, frozen, VT limiting, AIR-5), `supersonic` (supersonic inlet/outlet markers), `subout`/`subout_am` (subsonic outlet branch). Step 8 variants `sc_*` (super_cat: supercatalytic, partially catalytic explicit, Gupta-Yos, Sutherland, Green-Gauss, heat-flux wall, explicit, N2, Jacobi) + `partial_cat`, `axi_visccone`: device transport, viscous residual (Viscous stage), NS walls, viscous far field. | Strict build: `AB OVERALL: PASS` (0 non-bitwise entries). |
| `ab_resident.sh` (Step 10: `NP=2`, MPI build) | Step 6: device-resident mode (with `SU2_KOKKOS_PRECOND_VERIFY=1`, `SU2_KOKKOS_NEMO_POISON=1`) vs `SU2_KOKKOS_NEMO_RESIDENT=0`, 21 variants, plus the per-iteration transfer ledger of both (the ON ledger includes the PRECOND_VERIFY matrix download / precond upload). Step 8: 13 NS variants (`sc_*`, LIFT/DRAG/TOTAL_HEATFLUX in the screen history: Friction_Forces host sync; `sc_output`: volume output every 3 iterations, .vtk compared too). | Strict build: `AB RESIDENT OVERALL: PASS` (bitwise restart + history, precond A/B 0 non-bitwise). |
| `check_nonnemo_kokkos.sh` | ENABLE_KOKKOS=YES on the QuickStart NACA0012 Euler case (FGMRES+ILU, BCGSTAB+JACOBI), OLD vs NEW binary. | Bit-identical (the shared linear-algebra changes do not alter non-NEMO solvers). |
| `NEMOGasKokkos_validation` (UnitTests, `ninja -C <build> UnitTests/nemo_gas_kokkos_validation`, run `... 5000 1e-10`) | Pointwise device thermo / chemistry / Step 8 transport (WILKE, GUPTA-YOS, SUTHERLAND) vs CSU2TCLib. | Strict build 100 % bitwise; PASS in both builds. |
| `cuda_compile_check.sh` | CUDA compile check with clang 18 (no GPU, no nvcc): full device codegen (PTX + ptxas, `-v` stats) for sm_70 and sm_90 of every TU with Kokkos device code, against a clang-built Kokkos CUDA, plus an nvcc-like pass rejecting constexpr host calls in device code. Paths / assumptions in the header; see NEMO_KOKKOS_PORT_PLAN.md "CUDA compile check". Does not catch the nvcc extended-lambda rules (audit by hand). | `CUDA COMPILE CHECK: PASS` |
| `check_converged.sh` | Converged-solution comparison. Note: invwedge_ausm stalls near rms[Rho_0] ≈ -2.7 and does not converge. | |

Debug environment variables (ENABLE_KOKKOS= YES): `SU2_KOKKOS_NEMO_HOST=c2p,grad,lim,dt,upwind,source,bc,transport,viscous|all` forces stages to the host (`transport`: NS transport properties on the host with the per-point gas-state replay; `viscous`: host viscous residual); `SU2_KOKKOS_NEMO_EAGER=1` downloads the device residual accumulator after every device stage; `SU2_KOKKOS_NEMO_MIXED=1` lets device stages upload a non-zero host accumulator (after a host stage); `SU2_KOKKOS_STAGE_VERIFY=1` per-stage A/B. Step 10: `SU2_KOKKOS_NEMO_HALO=host` (resident halo exchange through the host containers + host comms, A/B), `=none` (debug negative control: no resident halo exchange, results must change); `SU2_KOKKOS_NEMO_EDGE=atomic|color|level` (edge assembly of the upwind / viscous kernels: atomics (default), balanced edge colouring, order-preserving levels), `SU2_KOKKOS_NEMO_EDGE_GROUP=<n>` (colour group size; default 1 on device backends, `EDGE_COLORING_GROUP_SIZE` on host backends). Step 6: `SU2_KOKKOS_NEMO_RESIDENT=0` disables the device-resident mode; `SU2_KOKKOS_NEMO_POISON=1` NaN-fills stale host copies (debug); `SU2_KOKKOS_PRECOND_VERIFY=1` compares the device Jacobi/ILU(0) build with the host build.

Batch A (2026-11-20): new variants in `ab_variants.sh` / `ab_resident.sh`: `am_impl am_first` (AUSM+M, device pressure sensor), `cfl_ausm cfl_am cfl_sc` (CFL_ADAPT with growth, clamp, reset and per-point reduction), `axi axi_gg axi_inv axi_expl` (axisymmetric source + auxiliary gradients), `supout_am supin_am supinout_am` (AUSM+M supersonic BCs, stale boundary-numerics replay), `tb_rk tb_rk4 rk_ausm rk4_am` (RUNGE-KUTTA_EXPLICIT, CLASSICAL_RK4_EXPLICIT), `dt2 dt1 dt_expl dt_unstcfl dt_sc` (dual time stepping, 3 time steps x 4 inner iterations). New A/B stages: `PressureSensor`, `AxisymAuxGradient`, `DualTimeSource`. `SU2_KOKKOS_NEMO_HOST=dualtime` forces the dual-time source to the host.
